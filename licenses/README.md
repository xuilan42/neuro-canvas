# Third-party licenses

The mod bundles four fonts, all under the SIL Open Font License 1.1 (full texts in this folder):

| Font | License text | Source |
|---|---|---|
| Inter | `OFL-inter.txt` | https://github.com/rsms/inter |
| Nunito | `OFL-nunito.txt` | https://github.com/googlefonts/nunito |
| Montserrat | `OFL-montserrat.txt` | https://github.com/JulietaUla/Montserrat |
| JetBrains Mono | `OFL-jetbrainsmono.txt` | https://github.com/JetBrains/JetBrainsMono |

The font files themselves come from https://github.com/google/fonts (`ofl/`).
